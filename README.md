# 🏠 House Price Prediction – Machine Learning Project

This project was developed as part of a Machine Learning course, aiming to predict housing prices using regression techniques.

## 📌 Objective
To predict house prices based on various features using a clean dataset. The task involves preprocessing, feature engineering, and training a regression model.

## 🔍 Workflow Overview

### 1. 🧼 Data Preprocessing
- Handled missing values in numeric and categorical features
- Encoded categorical variables using label encoding and one-hot encoding
- Removed outliers and applied transformations (e.g., log for skewed features)

### 2. 🛠️ Feature Engineering
- Combined related features (e.g., total square footage)
- Created new indicators based on domain knowledge
- Scaled features using standard scaling

### 3. 📊 Model Training
- Trained a linear regression model to predict prices
- Used `train_test_split` to validate the model
- Calculated R² score and mean absolute error

### 4. 📈 Evaluation
- Visualized prediction vs actual price
- Displayed residuals to check model accuracy
- Interpreted coefficients of the linear model

## 🛠️ Technologies Used
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- scikit-learn  
- Jupyter Notebook
